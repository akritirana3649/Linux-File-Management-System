
# Linux File Management System Using Shell Scripting

## Project Overview
The Linux File Management System is a menu-driven application developed using Bash Shell Scripting. It helps users perform basic file and directory management operations through a simple terminal interface.

## Objectives
- To understand Linux file management commands.
- To learn Bash Shell Scripting.
- To perform file operations through a menu-driven program.
- To understand file permissions and backup management.
- To maintain a record of user activities.

## Features
1. Create File
2. Delete File
3. Create Directory
4. List Files
5. Search File
6. Copy File
7. Change File Permissions
8. Write Content to File
9. Read File
10. Move File
11. Create File Backup
12. Restore Backup
13. View Activity Log
14. Exit Application

## Technologies Used
- Operating System: Ubuntu Linux
- Language: Bash Shell Scripting
- Editor: GNU Nano
- Terminal: Ubuntu Terminal

## Linux Commands Used
`touch`, `rm`, `mkdir`, `ls`, `find`, `cp`, `chmod`, `cat`, `mv`, `date`

## How to Run the Project

1. Open Ubuntu Terminal.
2. Navigate to the project folder.
3. Give execution permission:

   `chmod +x file_manager.sh`

4. Run the script:

   `./file_manager.sh`

5. Select an option from the menu.
